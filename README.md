# Airport Route Planner ✈️

Airport Route Planner is a web application that calculates the shortest flight route between airports using graph algorithms.  
The system integrates a C++ backend algorithm with a Node.js web server to compute optimal routes and display available flights.

#Live Demo 
https://airport-route-planner.onrender.com/

## Tech Stack

Frontend
- HTML
- CSS
- EJS Templates

Backend
- Node.js
- Express.js

Algorithm Engine
- C++ (Dijkstra Algorithm)

API
- AviationStack Flight API

Deployment
- Render

## Features

- Calculate shortest flight route between airports
- Graph-based route optimization using Dijkstra algorithm
- Display estimated distance and flight time
- Show available airlines and flight options
- Dynamic route visualization
